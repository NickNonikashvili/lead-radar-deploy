MFG 1.2–1.3 Functions and their graphs

Study notes for Functions and their graphs in M151Q Precalculus at Montana State University: the big ideas, key formulas, a worked example, common mistakes and an exam tip. The same topic has endless practice questions and flashcards in MatHub.

Big ideas

  • A function assigns exactly one output to each input. Inputs form the domain, outputs the range. Notation $y = f(x)$: $f$ is the rule, $x$ the input, $f(x)$ the output. $f(3)$ is a number, not a product.
  • Functions come four ways: a table, a graph, a formula, a description in words. Move between them fluently; exams ask you to read one and produce another.
  • Vertical line test: a graph is a function if no vertical line meets it twice. A table is a function if no input repeats with different outputs.
  • Reading graphs: $f(a)$ is the height at $x = a$. Solving $f(x) = c$ means finding the $x$-values where the height is $c$ (possibly several). Intercepts: $y$-intercept is $f(0)$; $x$-intercepts solve $f(x) = 0$.
  • Increasing/decreasing, maximum/minimum values, and where $f(x) > 0$ are all read off the graph as intervals of $x$.
  • Evaluate expressions like $f(a+h)$ by substituting the entire input for every $x$ and simplifying; keep parentheses.

Key formulas

Function notation
$$y = f(x):\quad \text{input } x \ \longrightarrow\ \text{output } f(x)$$
Intercepts
$$y\text{-intercept: } (0, f(0)),\qquad x\text{-intercepts: solve } f(x) = 0$$
Evaluating
$$f(x) = x^2 - 3x + 1 \Rightarrow f(a+1) = (a+1)^2 - 3(a+1) + 1 = a^2 - a - 1$$

Worked example

For $f(x) = x^2 - 3x + 1$, find $f(-2)$, $f(a+1)$, and all $x$ with $f(x) = 1$.
Show the solution
$f(-2) = 4 + 6 + 1 = 11$. $f(a+1) = (a+1)^2 - 3(a+1) + 1 = a^2 - a - 1$. $f(x) = 1 \Rightarrow x^2 - 3x = 0 \Rightarrow x(x-3) = 0$, so $x = 0$ or $x = 3$.

Common mistakes

  • Writing $f(a+1) = f(a) + 1$ or $f(a) + f(1)$. Substitute the whole expression.
  • Confusing "find $f(2)$" (plug in) with "solve $f(x) = 2$" (find inputs).
  • Answering an "on what interval is f increasing" question with y-values instead of x-values.
Exam tipEvery answer about a graph should say whether it is an x-value, a y-value, a point, or an interval. Graders look for that precision.
