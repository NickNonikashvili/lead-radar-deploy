MFG 4.3–4.4 Logarithms and their properties

Study notes for Logarithms and their properties in M151Q Precalculus at Montana State University: the big ideas, key formulas, a worked example, common mistakes and an exam tip. The same topic has endless practice questions and flashcards in MatHub.

Big ideas

  • A logarithm is an exponent: $\log_b x = y \iff b^y = x$. $\log_2 8 = 3$ because $2^3 = 8$. $\log x$ means base 10; $\ln x$ means base $e$.
  • Use logs to solve for an exponent: $3^x = 20 \Rightarrow x = \log_3 20 = \dfrac{\log 20}{\log 3} \approx 2.727$ (change of base).
  • Properties (products become sums, quotients differences, powers multipliers): $\log_b(MN) = \log_bM + \log_bN$; $\log_b(M/N) = \log_bM - \log_bN$; $\log_b M^p = p\log_bM$. Also $\log_b b = 1$, $\log_b 1 = 0$, $b^{\log_b x} = x$.
  • There is no rule for $\log(M + N)$. $\log(x+2) \ne \log x + \log 2$.
  • Logs of numbers $\le 0$ are undefined; the argument must be positive.

Key formulas

Definition
$$\log_b x = y \iff b^y = x$$
Properties
$$\log_b(MN) = \log_bM + \log_bN,\quad \log_b\frac MN = \log_bM - \log_bN,\quad \log_bM^p = p\log_bM$$
Change of base
$$\log_b x = \frac{\log x}{\log b} = \frac{\ln x}{\ln b}$$

Worked example

Solve $5\cdot 2^{x} = 80$ and write $\log\dfrac{x^3\sqrt y}{10}$ in terms of $\log x$ and $\log y$.
Show the solution
$2^x = 16 \Rightarrow x = 4$ (or $x = \log 16/\log 2 = 4$). $\log\dfrac{x^3\sqrt y}{10} = 3\log x + \tfrac12\log y - 1$.

Common mistakes

  • $\log(a+b) = \log a + \log b$ (wrong).
  • $\dfrac{\log a}{\log b} = \log a - \log b$ (wrong; it is $\log_b a$).
  • Taking the log of both sides before isolating the exponential term.
Exam tipTranslate every log statement into the exponential statement it means. Most "hard" log problems are one translation away from easy.
