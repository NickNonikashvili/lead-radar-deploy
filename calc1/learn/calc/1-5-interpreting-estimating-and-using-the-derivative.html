§1.5 Interpreting, estimating, and using the derivative

Study notes for Interpreting, estimating, and using the derivative in M171 Calculus I at Montana State University: the big ideas, key formulas, a worked example, common mistakes and an exam tip. The same topic has endless practice questions and flashcards in MatHub.

Big ideas

  • Units: $f'(a)$ has units of $f$ per unit of $x$. If $M(t)$ is mg at $t$ hours, $M'(t)$ is mg per hour.
  • The interpretation sentence. "$f'(a)=c$" means: when the input is $a$ (units), the output is changing at a rate of $c$ (units of $f$ per unit of $x$). Include: the input value with units, the direction (increasing/decreasing), the rate with units.
  • Estimating from data: use a difference quotient. Central difference (averaging both neighbors) is usually the best estimate when data on both sides is available.
  • Using the derivative: for small $h$, $f(a+h)\approx f(a) + f'(a)\,h$ (a step along the tangent line).

Key formulas

Forward difference
$$f'(a) \approx \frac{f(a+h)-f(a)}{h}$$
Backward difference
$$f'(a) \approx \frac{f(a)-f(a-h)}{h}$$
Central difference
$$f'(a) \approx \frac{f(a+h)-f(a-h)}{2h}$$
Tangent step
$$f(a+h) \approx f(a) + f'(a)\,h$$

Worked example

$W=f(c)$ is weight (lb) as a function of daily Calories $c$. Given $f(1600)=165$, $f(1700)=177$, $f(1800)=190$, estimate $f'(1700)$ three ways and interpret $f'(1500)=5$.
Show the solution
Forward: $\frac{190-177}{100} = 0.13$. Backward: $\frac{177-165}{100} = 0.12$. Central: $\frac{190-165}{200} = 0.125$ lb per (Calorie/day). Interpretation of $f'(1500)=5$: when a person eats 1500 Calories per day, each additional Calorie per day raises their weight by about 5 pounds.

Common mistakes

  • Leaving units off the rate, or off the input value.
  • Reporting a central difference as $\frac{f(a+h)-f(a-h)}{h}$ (forgetting the $2$).
  • Describing the function value instead of the rate ("the weight is 5 pounds").
Exam tipTemplate: "At $x = a$ [units], $f$ is [increasing/decreasing] at a rate of $|c|$ [output units] per [input unit]."
