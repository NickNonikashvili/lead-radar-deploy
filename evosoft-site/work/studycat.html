StudyCat

A free study hub for university courses.

StudyCat gives every class the same complete toolkit: a dashboard with the next exam, notes with worked examples, spaced-repetition flashcards, a quizzer that generates new problems forever, and exam prep. Students sign in to sync progress across devices, join discussions and use it offline as an installed app.

What it does

Everything in one study hub and community

Every class, complete

Dashboard, calendar, notes, formula sheet, flashcards, quizzer, exam prep and the syllabus rules.

Endless practice

Procedurally generated problems with typed or multiple-choice answers, practice or timed-exam mode.

Interactive tools

Function explorer, unit circle, grapher, Riemann sums, projectile simulator and a Python playground.

Moderated discussions

Threaded posts with votes, anonymous posting, reports, blocking, a language filter and a mod queue.

Canvas sync and planner

Real due dates from the Canvas calendar feed and a study planner that spreads work across days.

Works offline

Installs to a phone’s home screen; notes, flashcards and tools open without a connection.

Features

The details

For students

  • Spaced review flashcards
  • Smart review weighted to weak topics
  • Study planner per exam
  • Streaks, XP and daily goals
  • GPA calculator and focus room

Community

  • Reddit-style boards per class
  • Anonymous posts (moderators still see the author)
  • Reports, blocking and a language filter
  • Reply notifications and a weekly digest
  • Math rendering in posts

Running the site

  • Admin panel: members, bans, site settings
  • Class packs: add a course from one file
  • StudyCat Faculty for instructors
  • Static SEO study guides for every topic
  • Backups, cost alerts and a weekly report
